# คู่มือภาพหน้าจอ

ภาพ PNG จับจาก React routes จริงของโปรเจกต์ที่รันในเครื่อง เมื่อ 13 ตุลาคม 2569 ด้วยข้อมูลสมมติจากเกณฑ์ใน `supabase/seed/standard-2571-2573.json` วงกลมเลขเป็น DOM overlay ตอนจับภาพ ไม่ใช่ภาพหน้าจอที่สร้างด้วย AI

- join.png: ช่องรหัส / ข้อมูลบุคคล / บทบาท / เข้าร่วม
- score.png: หมวด / เปิดหัวข้อ / จำนวนหัวข้อที่ตอบ
- rating.png: The Must / คะแนน / เหตุผล
- report.png: ข้อมูลรอบ / ส่งออกภาพรวม / รายงานละเอียด
- admin.png: เมนูรอบ / หน่วยบริการ / หลักการประเมิน / สร้างรอบ

ปรับภาพเมื่อ label/layout เปลี่ยน โดยรัน dev server แล้วใช้ `node scripts/capture-guide.mjs` ต้องมี Playwright พร้อม Chromium; กำหนด `PLAYWRIGHT_MODULE` เป็น module path และ `CHROME_PATH` เป็น executable ได้หากใช้ runtime ที่ติดตั้งภายนอก

สคริปต์เชื่อมต่อ localhost เท่านั้น และดัก API ทั้งหมดด้วยข้อมูลตัวอย่าง ไม่สร้างผู้เข้าร่วม ไม่บันทึกคะแนน ไม่สร้างรอบจริง อนุญาตเพียงอ่านโลโก้สาธารณะจาก branding storage ภาพผู้ดูแลใช้ session จำลองภายใน browser context สำหรับการจับภาพเท่านั้น ไม่ได้แก้สิทธิ์แอปจริง

ตรวจทุกภาพด้วยตาหลังรัน โดยเลขต้องชี้เป้าหมายเดียวกับข้อความใน `src/pages/UserGuide.tsx` ชื่อ/รหัสในภาพเป็นข้อมูลตัวอย่าง ห้ามเปลี่ยนเป็นข้อมูลส่วนบุคคลจริง
